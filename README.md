# Final Task – Business Intelligence Analyst

## Project Overview

This project was completed as part of the Project-Based Internship with Bank Muamalat and Rakamin Academy.

The project focuses on data integration, data analysis, data visualization, and sales strategy recommendations based on transaction data from PT Sejahtera Bersama.

## Tools

- Google BigQuery
- SQL
- Looker Studio

## Project Process

1. Identifying Primary Keys
2. Identifying Database Relationships
3. Creating the MasterTable using Google BigQuery
4. Developing a Sales Performance Dashboard using Looker Studio
5. Providing data-driven sales strategy recommendations

## Project Deliverables

- MasterTable SQL Query
- Final Presentation
- Sales Performance Dashboard
